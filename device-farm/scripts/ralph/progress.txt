## Codebase Patterns
- Device Service uses FastAPI with lifespan context manager for startup/shutdown
- Services are instantiated as global singletons (e.g., `adb_service`, `device_service`)
- WebSocket manager handles subscriptions via device_id keys
- Redis is used for caching with `redis.asyncio` library
- Config settings are in `app/config.py` using `pydantic_settings.BaseSettings`
- Routes are organized in `app/routes/` and exported via `__init__.py`
- Models use Pydantic with `model_dump()` and `model_validate_json()` methods
