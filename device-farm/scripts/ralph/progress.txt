## Codebase Patterns

- Go services use internal/ for private packages
- Python services use FastAPI with async/await
- Frontend uses React with TypeScript and Vite
- WebRTC for real-time video streaming
- MinIO for object storage with async executor
- Safe Python execution with restricted builtins
- Safe JavaScript execution with Node.js VM sandbox
