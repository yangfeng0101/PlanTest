## Codebase Patterns
- device-svc uses SQLAlchemy async with asyncpg driver (same pattern as test-svc)
- Database URL is configured in config.py settings.DATABASE_URL
- Models inherit from Base in database.py (DeclarativeBase)
- Use SQLEnum for enum fields, String(36) for UUID primary keys
- Add indexes for foreign keys and frequently queried fields
- Pydantic schemas are defined in separate *_schemas.py files for API request/response
- Services use async session pattern with optional db parameter for transaction management
- Background tasks use asyncio.create_task in FastAPI lifespan context manager
- task-svc uses Celery for async task execution
